# ☁️ Azure & Cloud Computing Basics

## 📌 What is Cloud Computing?
Cloud computing means using internet-based servers to store data and run applications instead of using a local computer or physical servers.

**Example:**  
Saving files on Google Drive instead of your laptop.

---

## 🌩️ What is Azure?
Microsoft Azure is a cloud computing platform provided by Microsoft.

It offers services like:
- Virtual Machines (VMs)
- Storage
- Databases
- Networking
- AI and Analytics

**In simple words:**  
Azure allows you to rent servers and services instead of buying hardware.

---

## ❓ Why Do We Need Azure (Cloud)?
- 💰 Cost Saving – No need to buy hardware
- ⚡ Scalability – Increase or decrease resources anytime
- 🌍 Accessibility – Access from anywhere
- 🔒 Security – Managed by cloud providers
- 🚀 Fast Deployment – Launch applications quickly

---

## ☁️ Types of Cloud Computing (Deployment Models)

### 1. Public Cloud
- Resources are shared over the internet
- Managed by cloud providers

**Example:** Azure, AWS

---

### 2. Private Cloud
- Used by a single organization
- More secure and controlled

**Example:** Company’s internal data center

---

### 3. Hybrid Cloud
- Combination of Public and Private cloud

**Example:** Sensitive data in private cloud, applications in public cloud

---

## 🧩 Cloud Service Models

### 1. IaaS (Infrastructure as a Service)
- Provides virtual servers, storage, networking
- User manages OS, applications, and data

**Example:** Azure Virtual Machine

---

### 2. PaaS (Platform as a Service)
- Provides platform to develop and deploy applications
- No need to manage OS

**Example:** Azure App Service

---

### 3. SaaS (Software as a Service)
- Ready-to-use software over the internet
- No installation required

**Examples:** Gmail, Microsoft 365

---

## 🔥 Quick Comparison

| Service Model | Responsibility |
|--------------|---------------|
| IaaS         | You manage most things |
| PaaS         | You manage only code |
| SaaS         | You just use software |

---

## 🎯 Summary
- Cloud Computing = Use servers over the internet
- Azure = Microsoft cloud platform
- IaaS = Infrastructure
- PaaS = Platform
- SaaS = Software
